# Milestones

Programme-level checkpoints. Tick these off as they happen; tag the
matching git commit so the repo history lines up with real progress:

```
git tag -a milestone-topic-selected -m "Topic finalised: <name>"
git tag -a milestone-proposal-submitted -m "Proposal submitted"
```

- [ ] Explore all priority areas in `00-admin/areas-index.md`
- [ ] Build a preliminary literature map for the strongest 2–3 areas
- [ ] Identify recurring limitations / unresolved problems per area
- [ ] Generate a shortlist of candidate research gaps
- [ ] Shortlist and contact potential supervisors (`supervisor-log.md`)
- [ ] Select final topic
- [ ] Prepare and submit research proposal
- [ ] Ethics / data-access approvals (if required)
- [ ] First simulation study complete
- [ ] First real-data application complete
- [ ] Draft Paper 1
- [ ] Submit Paper 1
- [ ] Thesis full draft
- [ ] Thesis submitted
